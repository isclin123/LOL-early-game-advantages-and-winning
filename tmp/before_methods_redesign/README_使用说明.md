# LOL课程项目最新版本

选题：**Early Game Advantages and Winning in League of Legends**，研究早期优势与最终胜负的关系。

按你的要求：英语、普通表述尽量简单、保留统计术语、使用R、明确列出10个问题、一页、不写Semester Plan、附可点击的数据源链接。

## 文件

- `output/LoL_Project_Proposal.pdf`：一页英文proposal。
- `output/LoL_Project_Proposal.docx`：可编辑Word版本。
- `output/LoL_Project_Proposal.md`：同内容纯文本版本。
- `02_ten_research_questions.md`：每题的数据与变量、方法、R工具、预期结果、限制、关键词和4句话，共10题40句话。
- `01_data_and_methods.md`：变量定义、样本筛选、统计分析和预测验证的详细说明。
- `audit/data_audit.md`：R数据核验记录。

## 为什么采用LCK和LEC

本轮实际下载了ChainCC标为2024、2025、2026的团队文件，然后根据真实比赛日期筛选2024—2025。不能直接把文件标签当作全部比赛的年份。

原候选样本含LCK、LEC、LPL共3,159场。其中LPL的1,522场缺少可用的10／15分钟总经济字段，并出现零填充值。为了不把缺失的经济差误读成双方持平，本次早期优势研究排除这些LPL记录，保留**LCK和LEC的1,637场**：2024年776场，2025年861场。这是快照中可用的比赛，不声称覆盖所有官方比赛。

每场先配对蓝红双方，再保留一行。2024年用于建模，2025年用于最终预测验证；赛后总击杀、总经济等不能用来预测15分钟时的结果。

## 用中文理解这10题

1. 蓝方是否比红方更容易获胜？
2. 15分钟的经济领先与胜负有什么关系？
3. 已知经济差后，击杀领先还能提供多少信息？
4. 已知经济差后，经验领先还能提供多少信息？
5. 已知经济差后，补刀领先还能提供多少信息？
6. 考虑10分钟时的经济差后，接下来5分钟扩大优势是否与获胜有关？
7. 15分钟落后至少2,000经济时，有多大比例最终翻盘？
8. LCK与LEC把经济优势转为胜利的关系是否不同？
9. 这种关系是否随游戏版本变化？
10. 15分钟的信息比10分钟的信息能提高多少预测表现？

目前只完成数据可行性核验和研究设计，没有拟合模型、计算翻盘率或得出问题答案。Proposal里的预期均为待检验假设。

## 复现

用R运行`source("scripts/01_audit_data.R")`可复核现有原始文件；脚本从自身位置确定项目目录，避免个人R配置改变工作目录。`scripts/download_data.py`负责取得公共文件，`scripts/build_proposal.py`只负责文档排版，统计研究仍使用R。原始下载的链接、大小和哈希保存在`audit/source_manifest.json`。

上一级目录内的Dota 2文件属于之前的选题草稿，不是当前要提交的版本。老师的完整rubric尚未提供，课程名称及署名格式可按其要求补充。
